# ATM Management System
## Overview
This is a Python-based ATM Management System. The system simulates ATM operations through 3 different roles: Customer, Admin, and Technician. This project demonstrates practical python programming, object-oriented design, modular architecture, file-based data persistence, transaction processing, input validation, error handling, and basic secure password managemnet.

**Important Note**: This project is an educational simulation. It is not intended for real banking or financial transactions, and does not implement all the security controls required for a real banking system.
## Features
### Customer
1. Balance Inquiry: View the current account balance.
2. Withdrawal: Perform withdrawal with input cash amount and balance validation.
3. Deposit: Perform deposit with input cash amount and balance validation.
4. Password Change: Change account password after current password verification and new password hashing.
5. Transfer Funds: Transfer funds between customer accounts. Update account balances and record transactions.
### Admin
1. Create Customer Account: Create a new customer account.
2. Delete Customer Account: Delete an existing customer account.
3. Modify Customer Information: Change a customer's name, password, or both.
4. View Customer Account Information: View a specific customer account details.
5. Change Customer Account Status: Change a specific customer account status (Active/Frozen).
6. View Customer Transaction History: View transactions associated with a specific customer account.
7. View Transaction Logs: Review all recorded transactions.
### Technician
1. View ATM Health: View ATM ID, Status, Software version, Last maintenance date, Scheduled maintenance date, and Cash levels.
2. Schedule ATM Maintenance: Enter a date to schedule a specific ATM's maintenance.
3. Restart ATM Software: Simulate restarting a specific ATM's software.
4. Update ATM Software: Simulate updating a specific ATM's software.
5. Check ATM Cash Levels: Check the amount of cash in a specific ATM.
6. Refill ATM Cash: Refill the amount of cash in a specific ATM.
## Technologies Used
1. Python: Object-oriented programming.
2. CSV and File Handling: Persistent storage using structured text files.
3. PBKDF2-HMAC-SHA256: Password hashing with individual random salts.
4. Python Standard Library: pathlib, csv, hsshlib, secrets, hmac, getpass.

        **No external packages are required**
## Data Storage
The project uses CSV formatted text files to persist customer accounts, admin accounts, technician accounts, ATM configuration, and transaction records. The data_manager.py handles loading and saving records. Updates are wrriten to temporary files before replacing the original files to reduce the risk of leaving partially written data after a failed save.

## Security
* Passwords are stored as salted PBKDF2-HMAC-SHA256 hashes rather than plaintext.
* Password verification hashes the password the user entered using the stored salt, then checks whether the result matches the stored hashed password.
* Password input is hidden during entry on terminal by using Python's getpass module.

## Getting Started
### Prerequisites
1. Python 3 installed.
2. A terminal or IDE, such as VS Code.
### Installation
1. Clone the repository:

   >git clone https://github.com/LucielGameDev/ATM-Management-System.git
3. Prepare the required runtime data files in the data/ directory using the supplied templates. The system expects the following filenames:
    * admins.txt
    * customers.txt
    * technicians.txt
    * atm_config.txt
    * transactions.txt
4. Fill the txt files with correctly formatted records. transactions.txt can be left empty. Ensure that the account IDs in admins.txt, customers.txt, technicians.txt, andd atm_config.txt are unique (no 2 IDs are similar).
5. Ensure that stored passwords use the format generated by hashing_passwords.py. You can use generate_hashes.py to create unique salted hashes for admins, technicians, or customers by entering the password, copying the generated hash, and pasting it in it's designated space in the txt file. To run generate_hashes.py:

   >python generate_hashes.py
7. Run the system:

   >python main.py
